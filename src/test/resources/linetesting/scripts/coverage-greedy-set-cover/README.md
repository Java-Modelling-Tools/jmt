# JMT Coverage Optimization Tool

This suite of scripts analyzes JaCoCo coverage data to minimize the JMT test suite without losing code coverage. It identifies the "Champion" test files (those that provide the best coverage for specific classes) and generates an interactive HTML dashboard.

## Folder Structure
Ensure your files are organized as follows for the automatic paths to work:

```text
jmt/
├── src/test/resources/linetesting/
│   ├── output/
│   │   └── full_detailed_coverage.csv  <-- Input file generated by Java Test
│   │
│   └── scripts/
│       └── coverage-greedy-set-cover/  <-- YOU ARE HERE
│           ├── analyze_coverage.py
│           ├── generate_html_report.py
│           ├── main.py
│           └── output/                 <-- Created automatically
│               ├── detailed_suite_keep.csv
│               ├── detailed_suite_discard.csv
│               ├── class_golden_standard.csv
│               └── coverage_dashboard.html
```

## How to Run
1. **Prerequisites:**
    * Python 3.x installed.
    * No external libraries required (uses standard os, csv, json, subprocess).
2. **Run the Orchestrator:** Open your terminal in this folder and run:
```bash
python main.py
```
3. **View Results:**
    * Go to the `output/` folder created inside this directory.
    * Open `coverage_dashboard.html` in Chrome, Firefox, or Edge.

## What the Scripts Do
1. `analyze_coverage.py`
    * **Reads** the raw `full_detailed_coverage.csv`.
    * **Applies Champion Logic:**
        * For every Java class, it finds the "Gold Standard" (the test file that covers the most instructions).
        * It selects the minimum set of test files needed to ensure every class hits this Gold Standard.
    * **Outputs** three CSV files:
        * `detailed_suite_keep.csv`: Files you should keep.
        * `detailed_suite_discard.csv`: Redundant files.
        * `class_golden_standard.csv`: A map of every Class -> Best Test File.
2. `generate_html_report.py`
    * **Reads** the three CSVs generated above.
    * **Generates** `coverage_dashboard.html`.
    * **Features:**
        * **Search Bar:** Filter by File Name or Class Name (e.g., searching "`Solver`" expands the file that covers it).
        * **Charts:** Visual breakdown of Keep vs. Discard and top contributors.
        * **Detailed Views:** Expand rows to see exactly which instructions/branches/lines are covered for every class.
