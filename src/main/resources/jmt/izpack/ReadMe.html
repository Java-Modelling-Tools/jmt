Installation notes

It is recommended to UNINSTALL any previous version of Java Modelling Tools present on your PC before installing this new release.

What's new in version 1.4.0

JMCH

  • Added graphical animations to visualize the behavior of different scheduling algorithms on a single queue station: First Come First Served (FCFS), Last Come First Served (LCFS), Shortest Job First (SJF), Longest Job First (LJF), and Processor Sharing (PS).
  • Introduced animations to visualize the behavior of Round Robin (RR), Join Shortest Queue (JSQ), and Probabilistic routing policies.
  • Implemented a new multi-threaded animation engine that smoothly repaints graphical components frame-by-frame, complete with Play and Pause playback controls.
  • Added a new results table that captures live performance indices (such as Response Time, Queue Time, Number of Customers, and Throughput) directly from the graphical animation. This allows users to compare the results obtained from the animations with the correspondent metrics computed by the JSIMg simulator.

JSIM (FORK/JOIN)

  • Fixed an issue where simulations would stall prematurely in models using Fork nodes configured to produce multiple output jobs.

JMVA (WHAT-IF)

  • Fixed a bug in open models using What-If analysis where the System Throughput failed to update across iterations.

Working folder


A JMT working folder will be created in the home directory of the user to store examples and working files. For example, the files created by the Loggers (xxx.csv files) are by default located in this folder. The location of the working folder depends on the operating system:
  • Linux: /home/<user name>/JMT
  • Windows: C:\Users\<user name>\JMT
  • Mac OS X: /Users/<user name>/JMT
In older JMT versions, the default working folder was the JMT installation path.
