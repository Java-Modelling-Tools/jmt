# JMT Coverage Optimization Tool

This suite of scripts analyzes JaCoCo coverage data to minimize the JMT test suite without losing code coverage. It identifies the "Champion" test files (those that provide the best coverage for specific classes) and generates an interactive HTML dashboard.

## Folder Structure
Ensure your files are organized as follows for the automatic paths to work:

```text
jmt/
└── jmt-integration-tests/
    ├── target/jmt/integration/output/
    │   ├── jsim_coverage.csv     <-- Generated here after running tests
    │   ├── jmva_coverage.csv     <-- Generated here after running tests
    │   └── ...
    │
    └── src/test/resources/jmt/integration/scripts/
        └── coverage-greedy-set-cover/  <-- YOU ARE HERE
│           ├── optimize_coverage.py
│           ├── generate_html_report.py
│           ├── main.py
│           └── output/                 <-- Created automatically
│               ├── *_optimized_suite_KEEP.csv
│               ├── *_optimized_suite_DISCARD.csv
│               └── *_dashboard.html
```

## How to Run

### 1. Generate Coverage Data (JaCoCo Engine)
To generate the raw coverage data, you **must run the tests using Maven** so the JaCoCo engine successfully attaches. Do not run the tests using IntelliJ's standard run button, as the files will generate with empty data.

**To run via IntelliJ IDEA:**
1. Double-click the **`Ctrl`** key to open the "Run Anything" window.
2. Paste the following command and hit Enter:
   ```bash
   mvn test -Dtest=IntegrationTest -pl jmt-integration-tests
   ```
3. This triggers the JaCoCo engine over the test suites and calculates the coverage.

After the tests finish, the generated CSV files (e.g., `jsim_coverage.csv`, `jmva_coverage.csv`) will be created in `jmt/jmt-integration-tests/target/jmt/integration/output`.

### 2. Run the Optimization Orchestrator
* **Prerequisites:**
    * Python 3.x installed.
    * No external libraries required (uses standard os, csv, json, subprocess).
* Open your terminal in the script folder (`jmt/jmt-integration-tests/src/test/resources/jmt/integration/scripts/coverage-greedy-set-cover/`) and run:
```bash
python main.py
```

### 3. View Results
* Go to the `output/` folder created inside the script directory.
* Open the generated `*_dashboard.html` files in Chrome, Firefox, or Edge.

## What the Scripts Do
1. `optimize_coverage.py`
    * **Reads** the raw coverage CSVs generated by the Java tests.
    * **Applies Champion Logic (Set Cover Algorithm):**
        * Identifies every unique (Class, LineNumber) pair covered by the entire test suite.
        * Loops to find the test file that covers the highest number of 'Not-Yet-Covered' lines, adding it to a KEEP list.
    * **Outputs** two CSV files per test component:
        * `*_optimized_suite_KEEP.csv`: Files you should keep.
        * `*_optimized_suite_DISCARD.csv`: Redundant files.
2. `generate_html_report.py`
    * **Reads** the CSVs generated above.
    * **Generates** an interactive HTML dashboard (`*_dashboard.html`).
    * **Features:**
        * **Search Bar:** Filter by File Name or Class Name.
        * **Charts:** Visual breakdown of Keep vs. Discard and top contributors.
        * **Detailed Views:** Expand rows to see exactly which instructions/lines are covered for every class.
